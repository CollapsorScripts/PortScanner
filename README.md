# PortScanner

TCP-сканер для IPv4, IPv6 и DNS-имён. Проверяет порты обычным подключением и сразу закрывает соединение. Работает на стандартной библиотеке Go 1.25.5.

## Запуск

```sh
make build
./bin/portscanner -ports 22,80,443,8000-8010 127.0.0.1
./bin/portscanner -all -timeout 1s -workers 50 localhost ::1
./bin/portscanner -json -ports 80,443 localhost > results.jsonl
```

Флаги ставятся перед хостами. По умолчанию проверяются порты 22, 80 и 443, одновременно выполняется до 100 подключений, таймаут каждого — 500 мс.

Обычный вывод содержит только открытые порты. `-all` показывает каждую проверку, `-json` выдаёт все результаты в формате JSON Lines. Ошибки и итоговая статистика идут в stderr, поэтому их можно отделить от результатов перенаправлением вывода.

Ctrl+C и SIGTERM на Unix останавливают проверку. Код выхода: `0` — проверка завершена, `1` — ошибка сканирования или записи, `2` — неверные параметры запуска, `130` — остановка по сигналу. Закрытый порт, таймаут подключения и недоступный узел считаются результатами проверки, а не ошибкой запуска.

## Структура

```text
cmd/portscanner/    точка входа и обработка сигналов
internal/config/   параметры запуска
internal/app/      запуск сканирования и вывод результатов
pkg/portscan/      сканер, порты, разбор хостов и сетевые ошибки
```

Модуль называется `portscanner`, библиотека импортируется как `portscanner/pkg/portscan`.

## Использование в коде

```go
import (
    "context"
    "fmt"
    "time"

    "portscanner/pkg/portscan"
)

func scan(ctx context.Context) error {
    scanner, err := portscan.New(
        portscan.WithConcurrency(50),
        portscan.WithConnectTimeout(time.Second),
    )
    if err != nil {
        return err
    }

    ports, err := portscan.ParsePorts("22,80,443,8000-8010")
    if err != nil {
        return err
    }
    results, err := scanner.Scan(ctx, []string{"127.0.0.1", "::1"}, ports)
    if err != nil {
        return err
    }
    for result := range results {
        fmt.Printf("%s %d %s\n", result.Host, result.Port, result.State)
    }
    return ctx.Err()
}
```

У библиотеки таймаут по умолчанию — 2 секунды. Лимит подключений общий для всех вызовов `Scan` одного экземпляра. `WithResultBuffer` задаёт буфер результатов, `WithDialer` и `WithResolver` позволяют подменить сеть и DNS в тестах.

Порты можно собрать через `Ports`, `Range` и `Union`. Повторы и пересекающиеся диапазоны объединяются. Ошибку построения набора возвращает `PortSet.Err()` или `Scan`; для проверки ошибок подходят `errors.Is` и ошибки `ErrInvalidPort`, `ErrInvalidRange`, `ErrInvalidHost` и другие из пакета.

Несколько DNS-имён могут вести на один IP: он проверяется один раз и попадает в результаты под первым именем. Если у имени несколько адресов, проверяются все. Ошибка DNS приходит в `Result.Err` вместе со `StateError`, отдельно для каждого порта. Порядок результатов зависит от скорости подключений.

Результаты нужно читать до закрытия канала либо отменить контекст. При медленном чтении сканер ждёт, при отмене прекращает работу и может отбросить оставшиеся результаты. Прерванное сканирование определяется по `ctx.Err()`.

Поддерживаются только TCP-подключения. CIDR, UDP, SYN-сканирование и Unicode-имена не поддерживаются. IPv6 с зоной принимается, но `Result.IP` типа `net.IP` не хранит зону: исходный адрес остаётся в `Result.Host`.
